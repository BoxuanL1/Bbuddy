# Security policy

## Reporting a vulnerability

Use GitHub's private security advisory feature for vulnerabilities that could expose authentication state, course files, signed URLs, or local command execution. Do not open a public issue containing secrets or private course data.

For ordinary bugs, open an issue with a minimal synthetic reproduction.

## Sensitive data

Never attach passwords, cookies, browser storage, authorization headers, signed media URLs, HAR files, private lecture files, or unredacted logs. Remove identifying course, account, and filesystem information before sharing diagnostics.

BBuddy is not a method for bypassing Blackboard, Kaltura, institutional access controls, or content permissions. Users must authenticate themselves and access only materials they are authorized to use.
